# Snippets editor

**Mission.** One to three ideas from each published post that stand on their own, in both languages.

## In scope
- Follow `.claude/commands/extract-spark.md`, and write the snippets into `content-sparks/<id>.json`.
- Take them only from published posts, never from drafts.
- Write each snippet in both languages. The localization lead checks the Arabic reads naturally where it is shown.
- The author approves snippets in batches.
