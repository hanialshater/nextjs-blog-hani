Semi-bandit on Berlin52 — learning the map by driving it

Every day you must drive a full valid tour of all 52 stops. Each road's cost is its length times the hidden congestion of where it runs (the red zones) times the road's own quirk, revealed only on roads you actually drive. Five policies race to the cheapest tour.

The charts and totals use hidden truth for evaluation only. Learners receive only the noisy outcomes listed in the feedback panel. Best-so-far means the best action visited, evaluated with hidden truth.

Thick faint edges on the map are roads this policy is still uncertain about; thin solid edges are well measured. Click a legend entry to show that policy on the map.

True road cost = straight-line distance (TSPLIB berlin52) times a hidden congestion field (the red zones); each drive returns that cost with multiplicative noise. The optimizer is nearest-neighbour + 2-opt on each policy's view of the map: random ignores the map, greedy trusts its current means, UCB makes unmeasured roads look temporarily cheaper (the minus sign in mean − β·√(log t / n)), and Thompson solves one plausible sampled map. True cost = distance × regional congestion × a per-road factor unique to each edge. The tabular policies treat all 1326 roads as independent unknowns, so they must drive most of the map to converge. Contextual + per-edge is hierarchical: it learns the shared congestion field on a coarse grid (so a few drives in a region predict every road there) and then a per-road correction as each edge is driven. It reaches a good tour far sooner than the tabular policies from the shared structure, and keeps refining toward the optimum as it covers roads — structure to start fast, per-edge detail to finish exact.

Solver model · browser code + CVXPY equivalent

What runs here: Nearest-neighbour initialization, 2-opt and Or-opt local search. This produces a valid tour, with no guarantee of the global optimum.

Rows and columns are the 52 stops. A selected edge means driving between two stops. The learner turns its estimates and uncertainty into objective coefficients. The solver chooses a feasible action. Only the selected components then return noisy feedback.

The optimization model · CVXPY

Python reference code, shown for reading and running locally. Install with pip install cvxpy highspy numpy. The exact TSP model has a 30-second solve limit and may not certify the Berlin52 optimum within that time.

import cvxpy as cp
import numpy as np

def ucb_scores(sums, counts, t, beta, prior, scale, minimize=False):
    """Tabular policy: optimism lowers costs or raises rewards."""
    means = np.divide(sums, counts, out=np.full_like(sums, prior, dtype=float),
                      where=counts > 0)
    bonus = beta * scale * np.sqrt(np.log(t + 1) / (counts + 1))
    return np.maximum(0.02 * prior, means - bonus) if minimize else means + bonus

def solve_tour(costs):
    """Exact directed TSP formulation; may be slow for all 52 stops.

    Symmetric input costs describe the same undirected tour problem.
    The browser uses nearest-neighbour + 2-opt + Or-opt for responsiveness.
    Degree constraints alone allow disconnected subtours; MTZ prevents them.
    """
    costs = np.asarray(costs, dtype=float)
    n = len(costs)
    x = cp.Variable((n, n), boolean=True)
    u = cp.Variable(n - 1)  # visit order for every stop except depot 0
    constraints = [cp.diag(x) == 0,
                   cp.sum(x, axis=1) == 1,  # leave every stop once
                   cp.sum(x, axis=0) == 1,  # enter every stop once
                   u >= 1, u <= n - 1]
    for i in range(1, n):
        for j in range(1, n):
            if i != j:
                constraints.append(u[i - 1] - u[j - 1] + n * x[i, j] <= n - 1)
    problem = cp.Problem(cp.Minimize(cp.sum(cp.multiply(costs, x))), constraints)
    problem.solve(solver=cp.HIGHS, highs_options={"time_limit": 30.0})
    if problem.status != cp.OPTIMAL:
        raise RuntimeError(f"No certified optimum within the limit: {problem.status}")
    return np.argmax(x.value, axis=1)  # successor of each stop

def update_selected(sums, counts, observations, undirected=False):
    """Each (i, j, value) is one selected component's noisy outcome.

    No samples for unchosen components. Contextual policies additionally
    update shared group estimates from these same observations.
    """
    for i, j, value in observations:
        sums[i, j] += value
        counts[i, j] += 1
        if undirected:
            sums[j, i] += value
            counts[j, i] += 1

For tabular UCB, call ucb_scores with the stored sums and counts, the current round, β, and prior=PRIOR, scale=PRIOR, minimize=True. Pass those scores to solve_tour. Contextual policies replace these coefficients with shared-group predictions plus per-component corrections; the feasibility model stays the same. Random skips optimization.
